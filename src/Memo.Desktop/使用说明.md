# 白术便签 0.5.0

适用于 Windows 11 x64。完整解压到同一个文件夹后，双击 `白术便签.exe`。包内已包含 .NET 桌面运行时。

- 通知区域里的绿色便签图标是设置入口。左键打开设置，右键可打开设置或退出。Windows 把图标折叠时，请在时钟旁的「^」中查看。关闭设置只隐藏设置窗口。
- 点击任务左侧的方框可标记完成，再点一次恢复为待办。完成时方框内显示对号，任务正文加删除线。每项任务最多显示两行，第一行右侧是排序。点击正文可编辑，锁定时可查看全文。待办栏显示待办与已完成的条目数。删除条目请在设置的「任务管理」中操作。
- 在设置的「日程表」中按星期添加默认待办。当天的默认待办自动排在手动待办上方。换日后更新默认待办，手动待办会保留。在「任务管理」删除当天的默认待办只影响当天，在「日程表」删除则会取消这项每周安排。
- 待办栏的「＋ 新增」默认在底部，可在「基础设置」中移至顶部。字号用「−」和「+」调整，预览后点「应用字号」。
- 拖动待办栏顶部留白可移动窗口，拖动边框或角落可调整宽高，松手自动保存。
- 在「便签设置」中选择要显示的栏目，也可给便签添加分行线。便签栏可滚动，点击内容区域后可直接输入，内容自动保存。
- 在「皮肤设置」中切换日间或夜间模式。设置窗口右上角的「唤醒栏目」可把当前启用的栏目带到前方。
- 右键待办栏或便签栏可关闭该栏目或退出程序。关闭最后一个栏目会退出程序，下次启动时会重新显示该栏目。
- 「行为设置」包含进程优先级。「快捷键」可启用、修改或恢复默认快捷键，也会显示注册状态。
- 任务、便签内容和设置保存在 `%LOCALAPPDATA%\Memo\state.json`，旧版数据可直接读取。`state.json.bak` 是上一份有效快照。
- 可在「数据与权限」锁定或解锁任务编辑。当数据文件无法读取且有有效备份时，便签会先以只读方式显示备份，并提供恢复入口。恢复时原文件会另存为 `state.json.original-*`，备份文件也会保留。

## 默认快捷键

| 操作 | 组合 |
| --- | --- |
| 唤醒便签 | `Ctrl+Alt+M` |
| 切换置顶 | `Ctrl+Alt+T` |
| 快速新增 | `Ctrl+Alt+N` |
| 打开设置 | `Ctrl+Alt+O` |
